PART 2 - GOOGLE CLASSROOM FEATURE (BUILT)
====================================================================

What students get:
- Connect their Google Classroom account once (Google Classroom page ->
  "Connect Google Classroom").
- Dashboard card "Next in Google Classroom": the next 3 things to
  submit, with due time ("Due tomorrow", "2 days overdue").
- Google Classroom page:
  * Counts: Missing / Due in 7 days / Lab work to do / Turned in
  * Filters: To do / Lab work / Turned in / All
  * Each item shows course, topic, due date, status, points and grade
- "Submit in Classroom" button opens that student's own page for the
  item in Google Classroom, where they attach files and press Turn in.

Lab work: Google Classroom has no "lab" type. An item counts as lab work
if its Classroom topic or title contains "lab" or "laboratory".

How it works:
- Read-only access only. The portal never submits work itself.
- Coursework is fetched live from Google and NOT stored. Only the
  Google login tokens are stored, encrypted.

Problems in the old Google Classroom code that were replaced:
- Privacy leak: it copied each student's Classroom work into the shared
  assignments table, which every user could see.
- Connecting would always fail: it never asked permission to read the
  student's email, but then tried to read it.
- It asked for teacher-level and write permissions. Now only read-only
  student permissions.
- It could not tell "to submit" from "turned in", ignored due times,
  and never saved renewed Google tokens.
- If access expires or is revoked, the page now shows a Reconnect button.
